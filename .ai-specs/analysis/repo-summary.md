## Position page

- **File:** `frontend/src/components/PositionDetails.js`
- **Component:** `PositionsDetails` (default export)
- **Route:** `/positions/:id`
- **Props:** none (reads `id` from URL via `useParams`)
- **Child components:** `StageColumn`, `CandidateDetails`
- **State:**
  - `stages` — array of `{ title, id, candidates[] }`
  - `positionName` — string rendered in `<h2 className="text-center mb-4">`
- **Data fetching (useEffect on `id`):**
  1. `GET http://localhost:3010/positions/:id/interviewFlow` → maps `interviewSteps` to stages
  2. `GET http://localhost:3010/positions/:id/candidates` → populates `candidates` per stage (matched by `candidate.currentInterviewStep === stage.title`)
- **Drag-and-drop wrapper:** `<DragDropContext onDragEnd={onDragEnd}>` from `react-beautiful-dnd`

## Drag-and-drop library

- **Package:** `react-beautiful-dnd` v13.1.1
- **Also installed (unused in position page):** `react-dnd` v16.0.1, `react-dnd-html5-backend` v16.0.1
- **Active DnD API (react-beautiful-dnd):**
  - `<DragDropContext onDragEnd={handler}>` — wraps all droppable areas
  - `<Droppable droppableId="<string>">` — each column; provides `provided.innerRef`, `provided.droppableProps`
  - `<Draggable draggableId="<string>" index={number}>` — each card; provides `provided.innerRef`, `provided.draggableProps`, `provided.dragHandleProps`
  - `onDragEnd(result)` — `result.source` (`droppableId`, `index`), `result.destination` (`droppableId`, `index`), `result.draggableId`
- **Playwright DnD simulation:** use `page.dragAndDrop(source, target)` or mouse drag sequence (`mouse.down`, `mouse.move`, `mouse.up`); `react-beautiful-dnd` v13 requires a mouse-sequence approach as `dragAndDrop` may not trigger its pointer events correctly.


- **Expected response:** 2xx (no body consumed — only `response.ok` checked)
